## Advanced Settings

- `mimo-copilot.baseUrl`: use a custom compatible endpoint when needed.
- `mimo-copilot.modelIdOverrides`: remap model IDs for a compatible gateway.
- `mimo-copilot.visionModel`: choose the fallback vision model used only for text-only MiMo models.
- `mimo-copilot.experimental.stabilizeToolList`: experimental option for more stable tool lists across turns.
